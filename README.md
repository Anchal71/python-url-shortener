# 🔗 Python URL Shortener

A simple web-based URL Shortener developed using Python and Flask.

## 📌 Project Description

This project converts long URLs into shorter URLs that are easier to share.

The application provides a simple web interface where users can enter a long URL and generate a unique short URL.

## ✨ Features

- Shorten long URLs
- Generate unique short codes
- Redirect short URLs to the original URL
- Simple and user-friendly web interface
- Built using Python and Flask

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
